# On Page SEO Quick Fix

Chrome extension that analyzes the page you are viewing and shows on-page SEO issues with a score and fixes.

It checks the title, meta description, headings, images, links, canonical and robots tags, Open Graph and X tags, structured data, and blocking scripts.

## Scripts

```bash
npm install
npm run dev
npm test
npm run build
```

Load the `dist` folder in Chrome as an unpacked extension. The side panel opens from the toolbar icon.
